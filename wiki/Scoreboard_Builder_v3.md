# Scoreboard Builder v3

**Version compatible :** Minecraft Bedrock

## Description
Outil pour construire et afficher des scoreboards personnalisés pour suivre les statistiques, objectifs, etc.

## Fonctionnalités clés
- Interface de création de scoreboard
- Affichage configurable pour joueurs

## Installation
Importer pack et configurer via commandes ou fichiers.

## Compatibilités
- Intégration avec d'autres mods qui lisent le scoreboard.

## Notes
Assurez‑vous de la compatibilité avec Lily's Better Scoreboards si les deux sont utilisés.
