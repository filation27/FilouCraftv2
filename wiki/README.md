# Wiki Mods Minecraft Bedrock — Téléchargeable

Ce dossier contient la documentation (format Markdown) pour une sélection de mods/addons compatibles Minecraft Bedrock. Téléchargez l'ensemble en ZIP :

https://github.com/filation27/FilouCraftv2/archive/refs/heads/mods-wiki.zip

Structure :
- Un fichier par mod dans ce dossier (README.md + fichiers .md par mod)
- Chaque fiche contient : description, fonctionnalités, installation, compatibilités, dépendances, liens et notes

Remarques :
- Les informations sont générales et doivent être validées avec les pages officielles des mods (liens non fournis par défaut). Si vous me donnez des liens officiels, je mettrai à jour les fiches.
- Les captures d'écran sont des placeholders ; vous pouvez uploader vos propres images dans assets/images et je mettrai à jour les fiches.
