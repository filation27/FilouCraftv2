# Fabulous Furniture

**Version compatible :** Minecraft Bedrock (vérifier la page officielle)

## Description
Ajoute une grande variété de meubles et éléments décoratifs (chaises, tables, canapés, étagères, lampes) pour meubler et personnaliser vos constructions.

## Fonctionnalités clés
- Meubles interactifs (s'asseoir, ouvrir portes/tiroirs)
- Objets décoratifs variés et stylisés
- Compatibilité avec les packs de ressources

## Installation
1. Téléchargez le fichier .mcpack ou .mcaddon depuis la source officielle.
2. Importez le fichier dans Minecraft Bedrock (double‑clic sur Windows, ou import via l'option "Importer" sur mobile).
3. Activez le pack de ressources et le pack de comportement dans le monde.

## Compatibilités & dépendances
- Généralement compatible avec les dernières versions Bedrock, mais vérifiez la date de mise à jour du mod.
- Peut entrer en conflit avec d'autres mods qui modifient les mêmes entités ou blocs.
