# Advanced Shop

**Version compatible :** Minecraft Bedrock

## Description
Système de boutique avancé pour vendre/acheter des items via commandes ou GUI.

## Fonctionnalités clés
- Création de shops, prix configurables
- Intégration économique possible

## Installation
Suivre les instructions fournies par l'auteur pour activer le shop et définir les items.

## Compatibilités
- Peut nécessiter un addon d'économie.

## Notes
Parfait pour serveurs RP/économie.
