# Red's More Structures

**Version compatible :** Minecraft Bedrock

## Description
Ajoute diverses structures supplémentaires aléatoires (villages, ruines, bâtiments) pour enrichir le monde.

## Fonctionnalités clés
- Variété de structures
- Loot et ennemis dans certaines structures

## Installation
Importer et activer les packs, puis générer un nouveau monde.

## Compatibilités
- Problèmes potentiels avec d'autres mods modifiant les structures.

## Notes
Vérifier la densité de génération selon les paramètres du mod.
