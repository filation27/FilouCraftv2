# Vanish

**Version compatible :** Minecraft Bedrock

## Description
Permet aux joueurs avec permissions (admins/mods) de devenir invisibles (fantômes) pour surveiller le serveur.

## Fonctionnalités clés
- Mode invisibilité pour joueurs
- Commandes pour toggler vanish
- Options de permission

## Installation
Importer, activer, configurer les permissions.

## Compatibilités
- Vérifier les plugins côté serveur qui gèrent les permissions.
