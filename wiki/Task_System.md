# Task System

**Version compatible :** Minecraft Bedrock

## Description
Système de quêtes/tâches pour donner des objectifs aux joueurs (ex. tâches journalières, récompenses).

## Fonctionnalités clés
- Création de tâches personnalisées
- Récompenses configurables
- Intégration possible avec scoreboard/permissions

## Installation
Activer le behaviour pack et configurer les tâches via les fichiers de config fournis.

## Compatibilités
- Souvent utilisé avec des systèmes de scoreboards et d'UI.

## Notes
Très utile pour serveurs vocationnels ou communautés.
