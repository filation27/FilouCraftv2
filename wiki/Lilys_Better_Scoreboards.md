# Lily's Better Scoreboards

**Version compatible :** Minecraft Bedrock

## Description
Amélioration et extension des scoreboards (affichage, triggers, stylisation) pour une meilleure expérience d'interface.

## Fonctionnalités clés
- Scoreboards stylés et dynamiques
- Intégration avec autres addons (tasks, permissions)

## Installation
Importer le pack et configurer via fichiers/commandes.

## Compatibilités
- Attention aux doublons si vous utilisez plusieurs plugins de scoreboard.

## Notes
Souvent utilisé conjointement avec Lily's Floating Texts.
