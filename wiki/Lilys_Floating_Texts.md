# Lily's Floating Texts

**Version compatible :** Minecraft Bedrock

## Description
Permet d'afficher des textes flottants (hologrammes) dans le monde pour indications, panneaux d'information, etc.

## Fonctionnalités clés
- Textes flottants personnalisables
- Options de visibilité et permissions

## Installation
Importer le pack et utiliser les commandes/fonctions fournies.

## Compatibilités
- Compatible avec plugins de permissions pour restreindre l'usage.

## Notes
Utile pour créer des panneaux d'information dynamiques sur le serveur.
