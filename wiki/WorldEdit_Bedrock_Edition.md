# WorldEdit Bedrock Edition

**Version compatible :** Minecraft Bedrock

## Description
Version Bedrock de l'outil WorldEdit : permet des sélections, transformations et copies rapides d'aires pour construction.

## Fonctionnalités clés
- Sélection d'aires et remplissage
- Rotation, copie, déplacement, remplacement
- Commandes puissantes pour l'édition rapide

## Installation
Installer le behaviour pack correspondant et suivre les instructions pour activer les commandes WorldEdit.

## Compatibilités
- Souvent dépendant d'une version serveur ou d'un addon spécifique pour Bedrock.
