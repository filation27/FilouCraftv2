# FilouCraftv2

Site statique modernisé (Tailwind) généré par l'assistant. Ce dépôt contient :

- index.html, about.html, products.html, contact.html, terms.html
- assets/images/placeholder.svg

Instructions rapides :

1) Clonez le repo :
   git clone https://github.com/filation27/FilouCraftv2.git

2) Vérifiez/Remplacez les images dans assets/images et mettez à jour le formulaire contact (Formspree) ou configurez votre backend.

3) Poussez les modifications et activez GitHub Pages : Settings → Pages → Source = branch 'gh-pages' / folder '/'.

Remarques :
- Le contenu textuel original peut être réutilisé si vous avez l'autorisation. Remplacez les placeholders par vos images.
- Si vous m'uploadez mirror.zip, je peux remplacer automatiquement les placeholders par les images extraites.
